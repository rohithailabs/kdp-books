# Count the Pumpkins: A Halloween Counting & Coloring Book — Manuscript

Trim size 8.5" x 8.5". Interior: black line art only, one number per page. Total interior pages: 26 (3 front matter + 20 number pages + 2 bonus pages + 1 closing certificate).

Every number page (4-23) follows the same on-page layout: a large tracing numeral, the number word, a themed picture with the exact quantity of objects to count and color, and a row of small tracing/matching boxes equal to the number so the child can check off each object as they count it.

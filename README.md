# KDP Seasonal Activity Book Catalog — Halloween / Christmas / New Year 2026

Eight low-text, illustration-driven activity & coloring books for kids ages 4-8, built for Amazon KDP print-on-demand. Each book folder is fully self-contained and production-ready: a page-by-page manuscript, an illustration brief for every page, and a KDP publishing/metadata sheet.

## Why this catalog shape

- **Activity/coloring format** (not a story picture book) means the art carries the book — page count and volume matter more than prose, and a single illustrator or AI-art workflow can produce dozens of interior pages faster than a narrative book needs custom character continuity.
- **3 per theme for the two biggest seasons (Halloween, Christmas), 2 for New Year** (shorter shopping window between Dec 26–Jan 1) — spreads risk across formats (coloring / mazes-puzzles / counting-dot-to-dot) so a shopper browsing "Halloween coloring book for kids" and one browsing "Halloween activity book" both find a matching title.
- Each theme's 3rd book uses a *different* core mechanic (counting, dot-to-dot) than books 1–2 (coloring, mazes) to avoid cannibalizing the same keyword/search intent and to justify owning multiple listings per theme.

## Per-book folder contents

- `manuscript.md` — full page-by-page content plan: page number, activity type, exact on-page text (titles, instructions, labels), and answer key notes where relevant.
- `illustration-briefs.md` — a detailed art brief for every interior page: subject, composition, line-art style notes, and (for coloring pages) line-weight guidance for a printable, low-ink coloring-book style.
- `kdp-metadata.md` — trim size, page count, interior/cover specs, suggested categories, 7 backend keywords, title/subtitle, description copy, and pricing guidance.

## Shared production standards (applies to all 8 books)

- **Trim size:** 8.5" x 8.5" (square, standard for kids' activity books — easy to hold, good shelf presence) unless a book's metadata sheet says otherwise.
- **Interior:** black-ink line art only (no grayscale/color interior) — cheapest KDP print cost, and required for coloring pages anyway.
- **Line art style:** bold, simple outlines (2–3pt equivalent line weight), minimal fine detail, large open areas for young colorists, no scary/gory Halloween content — "cute-spooky" (friendly ghosts/pumpkins, not horror).
- **One activity per page**, generous margins (0.5"+ inner margin for perfect binding), page numbers bottom-center.
- **Every book opens with:** title page, "This book belongs to" page, and a short parent/caregiver note. **Every book closes with:** a "Great Job!" certificate page and (where applicable) an answer key section.
- **Reading level:** instructions written at a kindergarten level (short imperative sentences); a parent can also read instructions aloud to a 4-year-old.

# Santa's Dot-to-Dot Adventure
## Illustration Briefs

### Recurring Style Guide (applies to every interior page)

- **Line art only:** pure black line art on white, no gray fills, no shading, no color. Print-ready at 300 DPI, black ink only.
- **Dot style:** each dot is a small bold-outlined circle (filled solid black, ~0.08" diameter) with its numeral printed immediately outside the dot, positioned so the number never sits on top of the connecting-line path. Numerals use a clean, rounded, kindergarten-friendly sans-serif font, large enough to read easily (minimum ~14pt equivalent at trim size).
- **Numbering direction:** dots are numbered in a single continuous, non-crossing path around the shape's outline so the connected lines never overlap or tangle — critical for a clean reveal.
- **No preview art on the activity page itself:** the interior page shows only the numbered dots plus the caption naming the object (e.g., "a shining star") — never a faint outline of the finished picture. Provide the completed reference illustration to the printer/production file separately (not on the interior page) so the illustrator has a target shape to base dot placement on.
- **Difficulty scaling:**
  - *1–10 pages* (pages 5, 9, 12, 16, 22): simple, large, geometric-leaning shapes with generous space between dots — easiest tier, for the youngest colorists.
  - *1–15 pages* (pages 8, 10, 15, 18, 20, 23): slightly more complex silhouettes, moderate dot spacing.
  - *1–20 pages* (pages 6, 7, 11, 13, 14, 17, 19, 21, 24, 25, 26): most detailed shapes in the book, closer dot spacing, more contour changes to trace — page 26 (Santa's face) is the most detailed/final page.
- **Post-connect coloring:** every page's caption ends with "Now color it in!" — leave the completed shape as simple open line art (no dense interior detail) so it also works well as a coloring page once connected.
- **Character/prop style:** consistent rounded, friendly, big-eyed design matching the companion Christmas coloring and mazes-and-puzzles books in this catalog, so all three books feel like one family.
- **Composition:** each shape centered on the page with generous white space around it so dots and numerals stay uncluttered; a small non-numbered decorative doodle (snowflake, holly sprig) may sit in a page corner, clearly separated from the dot field so it can't be mistaken for part of the puzzle.
- **Trim size:** 8.5" x 8.5" page, safe area approx. 7.5" x 7.5", 0.5"+ inner margin clear of all dots/numerals for binding.
